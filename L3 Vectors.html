1 Introduction

There are several different data structures that are commonly used in R. The different data structures can be seen as different ways to organise data. In this exercise we will focus on vectors, which are the base data structure in R, and will also get an overview of the key data types (classes) that are found in R. At the end of this exercise you should know:

  • What are the data types commonly used in R.
  • What is a vector.
  • How to create vectors in an interactive R session.
  • How one can use R functions to determine the structure and class of a vector.
  • What basic operators you can find in R
  • How to subset vector using both indexes and operators.
  • Try some of the built-in functions in R.

1.1 Data types

From the lecture you might remember that all elements in any data structures found in R will be of a certain type (or have a certain class). The four most commonly used data types in R are: logical, integer and double (collectively called numeric), and character. The names hint at what they are.

  • Logical = TRUE or FALSE (or NA), can also be abbreviated T or F
  • Integer = Numbers that can be represented without fractional component
  • Double = Numbers with a fractional component, and special values like Inf, -Inf, and NaN
  • Character = Any string of text. Special characters must be escaped with \

Often, the class of an entry is automatically determined by R. For example if you save the value 5.1 as a variable, R will recognize it as numeric (double). If you instead have a text string like “hello world” it will have the class character. Below you will also see examples of how you can specify the class yourself, and not rely on R guessing it correctly.

If you are used to tools like Microsoft Excel or Google Sheets you might think “why do I have to think of data types? Excel does everything for me!” But remember, Excel is also doing guesswork behind the scenes, and they can get it wrong. For e.g. Excel will often automatically remove leading zeros from numerical values, if your values represent post codes or other IDs this could corrupt your data. It’s always best to know for sure.

1.2 Vectors in R

The most basic data structure in R are vectors. Vectors are 1-dimensional data structures that contain only one type of data (e.g. all entries must have the same class). To create a vector in R one can use the function c() (combine) as seen below. This example will create a vector named example.vector with 3 elements in it.

example.vector <- c(10, 20, 30)

If you need more information about the function c() you can always use the built-in manual in R. Typing ?c() will bring up the documentation for the function c().

Once you have created this vector in R, you can see its contents by simply typing its name in the R console and pressing return/enter.

example.vector
## [1] 10 20 30

If we for some reason only wanted to extract the value 10 from this vector we can use the fact that we know it is the first position to do so.

example.vector[1]
## [1] 10

Since a vector can only contain one data type, all members need to be of the same type. If you try to combine data of different types into the same vector, R will not warn you, but instead coerce (transform) all values to the most flexible type (From least to most flexible: Logical, integer, double, character). For e.g., adding a number to a logical vector will turn the whole vector to a numeric vector.

vec <- c(T,F,T,T)
vec
class(vec)
vec <- c(vec,2)
vec
class(vec)
## [1]  TRUE FALSE  TRUE  TRUE
## [1] "logical"
## [1] 1 0 1 1 2
## [1] "numeric"

To check what data type an object is, run the R built-in function class(), with the object as the only parameter.

class(example.vector)
## [1] "numeric"

If you for any reason want to have more information about any object you have stored in your R session the command str() is very helpful.

str(example.vector)
##  num [1:3] 10 20 30

1.3 Basic R operators

As in other programming languages there are a set of basic operators in R.

Operation Description Example Example Result
x + y Addition 1 + 3 4
x - y Subtraction 1 - 3 -2
x * y Multiplication 2 * 3 6
x / y Division 1 / 2 0.5
x ^ y Exponent 2 ^ 2 4
x %% y Modular arithmetic 1 %% 2 1
x %/% y Integer division 1 %/% 2 0
x == y Test for equality 1 == 1 TRUE
x <= y Test less or equal 1 <= 1 TRUE
x >= y Test for greater or equal 1 >= 2 FALSE
x & y Vectorized boolean AND c(T,F) & c(T,T) TRUE FALSE
x | y Vectorized boolean OR c(T,F) | c(T,T) TRUE TRUE
!x Boolean not 1 != 2 TRUE

Besides these, there are of course numerous more or less simple functions available in any R session. For example, if we want to sum all values in our example.vector that we discussed earlier, we can do that using addition:

example.vector[1] + example.vector[2] + example.vector[3]
## [1] 60

But we can also use the function sum() that adds all numeric values inside the vector.

sum(example.vector)
## [1] 60

To learn more about a function use the built in R manual as described earlier. If you do not know the name of a function that you believe should be found in R, use the function help.search() or use Google to try and identify the name of the command.
